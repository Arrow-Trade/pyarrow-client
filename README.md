# ArrowConnect – Official Python Client for Arrow API  

[![PyPI version](https://badge.fury.io/py/arrowconnect.svg)](https://badge.fury.io/py/arrowconnect)  
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)  
[![Python Versions](https://img.shields.io/pypi/pyversions/arrowconnect.svg)](https://pypi.org/project/arrowconnect/)  

ArrowConnect is the official Python client for the **Arrow Trading API**, designed to make it easy to build trading applications that connect with the Arrow platform.  

It provides a simple and intuitive interface to:  
- Fetch market data (quotes, OHLC, LTP)  
- Manage user sessions  
- Place, modify, and cancel orders  
- Access historical data  
- Subscribe to real-time WebSocket feeds  

---

## ✅ Features  
- **REST API wrapper** for all Arrow endpoints  
- **WebSocket streaming** for live ticks, order updates, and positions  
- **Thread-safe design** for high-frequency trading environments  
- **Lightweight and fast**, with minimal dependencies  
- **Fully typed methods** for better IDE experience
